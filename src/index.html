PaleoTree 使用說明

  1. 開啟樹檔或拖曳至畫布，從清單選擇樹。純性狀矩陣不含樹，無法直接繪製。
  2. 選定全樹一致的年代欄位，再按「驗證並顯示 Ma」。時間單位固定為 Ma；其他單位須先換算再匯入。年代備註可留白；只有檔案未記錄定根狀態時，才需指定是否使用目前的根。
  3. 若原始 0 表示最年輕化石而非現在，在「原始 0 對應的距今年代（Ma）」輸入其真實年代。全樹及年代區間會加上此值，枝長與原始資料不變。這是時間原點換算，不是重新定年；原始數值必須已是以 Ma 表示的時間。
  4. 時間枝長模式只使用檔案內既有年代作錨點；不能將替換數枝長改標 Ma。缺漏、未定根或衝突時保留一般模式。
  5. Ma 為距今百萬年；化石末端不強制對齊 0。點選節點可查看原始精度與 HPD／CredInt。
  6. 滑鼠拖曳平移；Ctrl＋滾輪或上方按鈕縮放；方向鍵平移，＋／−縮放。選取節點後可折疊；搜尋會展開路徑並定位。
  7. SVG／PNG 包含時間軸與格線。CSV 對可能的試算表公式文字加單引號。專案 JSON 可在下次開啟時還原設定。
  8. 上限：10 MiB、100 棵樹、總節點 200,000、每樹 1,000 tips、樹深度 512；專案 32 MiB。全樹 PNG 另受畫布尺寸限制。
  9. 不重新執行 tip-dating，不執行 NEXUS 指令。不支援未知比例或其他非平移式時間基準轉換。

相容性：已以合成資料與提供的三葉蟲共識樹驗證解析及時間原點換算；分析單位與校正值仍需研究者確認。未保證任意 XML 擴充或 NeXML network。P2 地質色帶與區間橫條尚未提供。

年代來源預設自動判斷：節點年代完整時優先直接使用，否則嘗試時間枝長與既有錨點；兩者皆不可用時保留一般模式。若需手動指定，展開「進階：年代來源」。自動判斷不代表已驗證時間單位與原點，仍須檢查設定後按「驗證並顯示 Ma」。
